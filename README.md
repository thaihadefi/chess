Chess is a minimalist, responsive two-player web chess platform built with React 19, Vite, and Chess.js. Designed with clean vector SVG pieces and standard FIDE board geometry, the application delivers a seamless pass-and-play experience featuring real-time move validation, visual legal-move assistance, king threat detection, pawn promotion handling, interactive move history tracking, and board orientation toggling.

---

## Key Features

### Gameplay & Move Validation
- **FIDE Rules & Move Validation:** Built on `chess.js` to ensure 100% adherence to official chess rules, including castling, en passant captures, pawn promotion, and draw condition detection (stalemate, threefold repetition, insufficient material, 50-move rule).
- **Visual Move Assistance:** Dynamic legal-move indicators for selected pieces, highlighting reachable empty squares with subtle dot overlays and hostile targets with high-visibility capture rings.
- **Square Identification Tooltips:** Interactive coordinate and piece tooltips on hover (e.g., `E1: White King`, `D1: White Queen`) providing immediate clarity for beginners learning algebraic notation and piece roles.
- **Standard International Board Geometry:** FIDE-compliant board layout featuring light square on bottom-right ($h1$), dark square on bottom-left ($a1$), and proper queen-on-color initial arrangement.

### Board Controls & Game Management
- **Board Orientation Toggling (`Flip Board`):** 180-degree board inversion allowing players to analyze and pass-and-play from either White or Black's perspective while keeping coordinates aligned.
- **Move History & Notation Log:** Chronological move logging formatted in standard algebraic notation (`e4`, `Nf6`, `O-O`), auto-scrolling to the latest move in a structured two-column move pair table.
- **Step-by-Step Move Undo:** State-restoring undo capability that reconstructs board positions, active player turns, captured piece inventories, and move histories.
- **Pawn Promotion Modal:** Contextual promotion modal presenting piece selections (Queen, Rook, Bishop, Knight) with vector previews upon reaching the terminal rank, with move cancellation support.

### Material Tracking & Game State
- **Captured Pieces Inventory:** Real-time mini-vector visualizer categorizing captured pieces for both sides to easily gauge material balance.
- **King Threat & Check Alert System:** Real-time check and checkmate detection highlighting the imperiled King's square with an urgent warning state alongside status banner updates.
- **Game Outcome Resolution:** Comprehensive outcome tracking distinguishing checkmate victories, stalemates, threefold repetition draws, and insufficient material draws.

## Technology Stack

- **Frontend:** React 19, JavaScript ES6+, HTML5 Semantic Elements.
- **Game Rules & Logic:** `chess.js` (FIDE rulebook validation, FEN serialization, legal move generator).
- **Styling & Design System:** Pure Vanilla CSS3, Custom Properties (CSS variables), Responsive Grid/Flexbox layouts, Plus Jakarta Sans & JetBrains Mono typography.
- **Build & Tooling:** Vite 8.

## Getting Started

### Prerequisites
- Node.js (`^20.19.0 || >=22.12.0`, required by Vite 8)
- Yarn or npm

### Quick Start

```bash
# Clone the repository
git clone https://github.com/thaihadefi/chess.git
cd chess

# Install dependencies
yarn install

# Run development server
yarn dev

# Build for production / preview the build
yarn build
yarn preview
```
